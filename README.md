### About

I build software at the intersection of **on-device AI**, **cybersecurity**, and **systems programming**.

Most of my time goes into:
- Running LLMs locally on phones — no cloud, no data leaks. Built the inference layer in C++ with `llama.cpp`, Metal (iOS), and NEON SIMD (Android).
- Training and publishing small language models. [SeaMora](https://ollama.com/aviksamantaofficial/seamora-mini) is a 1B reasoning model that fits in <1GB RAM.
- Building security tools — from OSINT scrapers and NIDS to hardware HID injection rigs with ESP8266.
- Shipping web apps on Vercel with Next.js, TypeScript, and React.

Recognized by **CERT-In / NCIIPC (Government of India)** for responsible vulnerability disclosures.

Currently **Founder & President** of [ZeroDay Alliance](https://democtf.zerodayalliance.com) (university cybersecurity community, 100+ members) and **R&D Head** at MintFire (security automation).

### Currently building

**[Fault](https://faultlm.vercel.app)** — On-device LLM runtime for Android and iOS. Download models, run them offline, chat, do OCR, voice — all local. No cloud.  
`Swift` `Kotlin` `C++` `llama.cpp` `Metal` `CoreML` `SIMD` → [Android](https://github.com/avik-root/Fault) · [iOS](https://github.com/avik-root/Fault-iOS) · [Website](https://faultlm.vercel.app)

**[SeaMora SLM](https://ollama.com/aviksamantaofficial/seamora-mini)** — 1B/1.5B parameter reasoning model fine-tuned on Gemma 3 with `<think>` chain-of-thought. GGUF quantized to ~500-815MB. Published on Ollama.  
`Python` `PyTorch` `GGUF` `LoRA` → [SeaMoraMini](https://github.com/avik-root/SeaMoraMini) · [Sea_SLM](https://github.com/avik-root/Sea_SLM)
