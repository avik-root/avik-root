# 🚀 Featured Projects

### 🔐 [W3Guard](https://github.com/avik-root/W3Guard)
A next-gen web vulnerability scanner featuring:
- ✅ Secure 2-step login with Super Key authentication
- 🟢 Real-time user activity tracking (online/offline)
- ⏳ Daily credit system for scan limits (10 scans/day)
- 🔍 Integrated with **Shodan**, **AbuseIPDB**, **VirusTotal** APIs
- ⚡ Built using **Flask** and **TailwindCSS** with a dynamic neon canvas UI

### 🌐 [MintFiber](https://github.com/anushagupta11/MintFiber)
Security-focused open-source organization crafting infosec tools featuring:
- 🌅 Day/Night animated backgrounds
- ✨ Floating logo animations and engaging UI
- 🧠 Community-driven security tools development

### 🛡️ [Blind-Header](https://github.com/avik-root/Blind-Header)
An open-source tool for bug bounty hunters:
- 🐞 Scans target URLs for missing or insecure HTTP security headers
- 🧠 Helps identify vulnerabilities like Clickjacking
- 🖥️ Tests if a URL is vulnerable to iframe-based attacks
- 🚀 Lightweight, fast, and easy-to-use Python-based tool
- 🔥 Great for pentesters and infosec professionals who need header analysis
